# My First Website

A simple responsive website created as a practical project to demonstrate website development and deployment using GitHub and Vercel.

## Project files

- `index.html` — webpage structure and content
- `style.css` — layout, colours and responsive styling
- `script.js` — interactive button behaviour

## Run locally

Open `index.html` in a web browser.

## Deploy with Vercel

1. Upload all project files to a GitHub repository.
2. Sign in to Vercel using GitHub.
3. Import the repository.
4. Select **Other** as the framework preset.
5. Leave the build command and output directory blank.
6. Click **Deploy**.

Vercel will publish the static website and provide a deployment URL.

## Custom domain

In the Vercel project, open **Settings → Domains**, enter a domain you own, and follow the DNS instructions shown by Vercel. A domain must be registered separately to use it as a working custom domain.
